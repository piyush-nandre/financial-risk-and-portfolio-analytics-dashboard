# Financial Risk & Portfolio Analytics Dashboard

## Overview

This project is a Power BI-based financial analytics dashboard designed to evaluate portfolio performance and risk across Indian equities, Exchange Traded Funds (ETFs), and cryptocurrencies.

The dashboard provides investors and analysts with actionable insights through performance tracking, risk assessment, and portfolio health evaluation using industry-standard financial metrics.

---

## Objectives

* Analyze portfolio performance across multiple asset classes.
* Measure risk using Volatility and Value at Risk (VaR).
* Evaluate risk-adjusted returns using Sharpe Ratio.
* Compare asset performance through normalized investment growth.
* Build an interactive Power BI dashboard for decision-making.

## Key Metrics

### Portfolio Return

Measures overall portfolio performance.

### Portfolio Volatility

Measures fluctuations in returns.

### Sharpe Ratio

Evaluates risk-adjusted returns.

### Value at Risk (VaR)

Estimates potential downside risk at 95% confidence.

### Portfolio Health Score

Custom portfolio quality metric combining return, risk, and diversification factors.

## Key Insights

* Cryptocurrencies delivered the highest returns but also carried significantly higher risk.
* ETFs provided diversified exposure with moderate risk profiles.
* Indian equities showed relatively stable performance compared to crypto assets.
* Risk-adjusted analysis highlighted assets with superior return-to-risk characteristics.
